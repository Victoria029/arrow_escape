# 一箭又一箭 (Arrow Escape)

## 游戏简介
这是一款使用 Python 和 Pygame-ce 开发的点击式箭头解谜小游戏。玩家需要观察棋盘上箭头的方向和遮挡关系，按照正确的顺序点击，使所有箭头飞出棋盘。

## 开发环境
- 操作系统：Windows 11
- 编程语言：Python 3.14
- 图形库：Pygame-ce 2.5.8
- 开发工具：PyCharm

## 安装和运行方法
1. 将本项目克隆到本地：
   git clone https://github.com/Victoria029/arrow_escape.git
2. 安装依赖环境：
   pip install -r requirements.txt
3. 启动游戏：
   python main.py

## 游戏操作说明
- **鼠标左键**：点击箭头尝试让其飞出棋盘。
- 如果箭头前方没有阻挡，箭头会平滑飞出并消失。
- 如果前方有阻挡，箭头会撞击并弹回，失误次数 +1。
- **撤销**：回退上一步操作。
- **提示**：高亮当前可以飞出的箭头。
- **重新开始**：重置当前关卡。
- **主菜单**：返回关卡选择界面。
- 失误次数达到 3 次本关失败；清空所有箭头即可通关，按空格键进入下一关。
